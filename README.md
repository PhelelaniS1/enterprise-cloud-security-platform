# Enterprise Cloud Security Platform on AWS

## Overview

This project demonstrates how to design, build, and secure an enterprise-grade cloud platform on Amazon Web Services (AWS) using Infrastructure as Code (Terraform), Kubernetes (Amazon EKS), DevSecOps practices, and AWS-native security services.

The platform is designed around cloud security engineering principles, emphasizing automation, least-privilege access, continuous security validation, monitoring, and incident response.

## Project Objectives

- Build secure AWS infrastructure using Terraform
- Deploy a production-ready Amazon EKS cluster
- Implement DevSecOps in a GitHub Actions CI/CD pipeline
- Enable AWS security services such as GuardDuty, Security Hub, Inspector, AWS Config, and CloudTrail
- Implement centralized monitoring and logging
- Automate incident response using AWS Lambda
- Demonstrate cloud security engineering best practices
